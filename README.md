# Security+ Notes (SY0-701)

## Security Controls

### Overview
Security controls are safeguards used to reduce risk and protect systems, data, and resources.

### Control Categories
- Technical → Firewalls, antivirus, encryption  
- Managerial → Policies, risk management, procedures  
- Operational → Day-to-day processes (training, monitoring, backups)  
- Physical → Locks, cameras, fences  

### Control Types
- Preventive → Stops attacks (firewalls)  
- Detective → Identifies activity (logs, IDS)  
- Corrective → Fixes issues (restoring backups)  
- Deterrent → Discourages (warning signs)  
- Compensating → Temporary fix (alternative control)  
- Directive → Tells users what to do (policies, training)  

### Exam Focus
- Categories vs Types (VERY common)
- Backups & patching = operational  
- Firewalls/encryption = technical  
- Policies = managerial

## CIA Triad

### Overview
The CIA Triad represents the three core principles of security.

### Key Points
- Confidentiality → Protect data from unauthorized access  
- Integrity → Ensure data is not altered  
- Availability → Ensure systems are accessible  

### Examples
- Encryption → Confidentiality  
- Hashing → Integrity  
- Backups → Availability  

### Exam Focus
- Hashing = integrity  
- Encryption = confidentiality  
- Backups = availability  
- Questions are scenario-based

## Risk, Threat, Vulnerability

### Overview
These terms are foundational to understanding security.

### Key Points
- Vulnerability → Weakness  
- Threat → Potential danger  
- Risk → Likelihood + impact  
- Exploit → Using a vulnerability  

### Exam Focus
- Know the difference between all four  
- Expect scenario questions  

---

## Authentication Factors

### Overview
Authentication verifies identity using different types of evidence.

### Key Points
- Something you know → Password  
- Something you have → Token / phone  
- Something you are → Biometrics  

### Exam Focus
- MFA = 2 or more factors  
- Know examples for each  

---

## Cryptography Basics

### Overview
Cryptography protects data through encryption and hashing.

### Key Points
- Symmetric encryption → One key (fast)  
- Asymmetric encryption → Public/private keys  
- Hashing → One-way function (integrity)  

### Exam Focus
- Hashing = integrity  
- Encryption = confidentiality  
- Digital signatures = integrity + non-repudiation  

---

## Non-Repudiation

### Overview
Ensures someone cannot deny their actions.

### Key Points
- Achieved using digital signatures  
- Proves origin and authenticity  

### Exam Focus
- Often tied to digital signatures

## Incident Response (PICERL)

### Overview
A structured process for handling security incidents.

### Steps
1. Preparation  
2. Identification  
3. Containment  
4. Eradication  
5. Recovery  
6. Lessons Learned  

### Exam Focus
- Know order  
- Questions ask “what comes next”
